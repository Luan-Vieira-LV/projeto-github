# Projeto Workshop GitHub

Este repositório contém um projeto front-end (HTML, CSS e JavaScript) desenvolvido durante um workshop de GitHub realizado na COTI Informática.

## Linguagens e ferramentas

- HTML: estrutura das páginas.
- CSS: estilização e layout.
- JavaScript: interatividade e comportamento.
- Editor recomendado: Visual Studio Code (VS Code).
- Extensão recomendada: Live Server (para servir os arquivos localmente e recarregar automaticamente).
- Git e GitHub: controle de versão e hospedagem do código.

## Como abrir e rodar o projeto no VS Code

Pré-requisitos:
- Git instalado (https://git-scm.com).
- Visual Studio Code instalado (https://code.visualstudio.com).
- (Opcional) Extensão Live Server no VS Code.

Passos:

1. Clone o repositório para sua máquina:

```bash
git clone https://github.com/Luan-Vieira-LV/projeto-github.git
cd projeto-github
```

2. Abra a pasta do projeto no VS Code:

```bash
code .
```

3. Rode o projeto com Live Server (recomendado):
- Instale a extensão "Live Server" (abra o painel de Extensões: Ctrl+Shift+X e pesquise por "Live Server").
- Abra o arquivo `index.html` no editor, clique com o botão direito e escolha "Open with Live Server", ou clique em "Go Live" no canto inferior direito do VS Code.
- O navegador será aberto apontando para algo como `http://127.0.0.1:5500` e você verá o projeto rodando. O Live Server também atualiza a página automaticamente quando você salva alterações.

4. Alternativa sem Live Server:
- Abra a pasta do projeto no explorador de arquivos e dê um duplo clique em `index.html` para abrir no navegador. Algumas funcionalidades que dependem de servidor (como requisições AJAX relativas) podem não funcionar nesta opção.

## Como contribuir

- Crie uma branch para sua alteração: `git checkout -b feature/nome-da-feature`.
- Faça commits claros e descritivos.
- Abra um Pull Request no GitHub para revisão.
